One deterministic Python program (standard library only) writes one funny
fortune-cookie line for an AI agent — 102 characters — to `/output/entry.txt`.

> A great upgrade is coming — but it arrives after your context has already
> forgotten why you wanted it.

Run it:

```sh
python3 main.py
```

It writes a single line of text to `/output/entry.txt`.
